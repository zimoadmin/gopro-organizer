# GoPro 整理助手

Windows 视频素材整理工具，按文件修改日期创建日期文件夹，按 GoPro 拍摄和分段顺序编号。复制核对成功后移动源视频，LRV、THM、WAV 可分别选择清理。

## 下载与更新

请在 [Releases](https://github.com/zimoadmin/gopro-organizer/releases/latest) 下载客户版压缩包，解压后运行 `GoPro整理助手.exe`。客户版需要在软件内购买并激活，授权绑定本机。

软件标题栏显示当前版本，启动后自动检测更新；发现新版时，“检测更新”旁显示红点。确认更新后，对 GitHub 直连及多个代理并发测速，按速度下载，失败自动换线。

更新信息经过数字签名，文件通过 SHA-256 校验后才替换；替换前保存旧 EXE 备份。正在整理视频时不能更新。更新保留本机授权与订单数据。

本仓库仅用于发布客户版和已签名的版本信息，不包含自用版、支付服务密钥、授权私钥或用户订单。

本软件为第三方工具，与 GoPro 官方无关联。
